# TaskFlow — Priority Manager ⚡️

Your deadlines, prioritized & never forgotten. TaskFlow is a sleek, front-end web application built to help you manage tasks efficiently through visual priority tracking and deadline management. 

## ✨ Features

*   **Priority-Based Tracking:** Assign tasks as *Urgent*, *High*, *Medium*, or *Low*. Visual indicator bars let you see what needs attention at a glance.
*   **Dashboard Stats:** Live counters for Critical tasks, tasks Due Soon, Total tasks, and Completed tasks.
*   **Smart Deadlines:** Calculates and displays days remaining, highlighting overdue tasks in red and upcoming tasks in orange.
*   **Filtering & Sorting:** Filter by Active, Done, or Urgent. Sort tasks by Newest, Deadline, or Priority.
*   **Persistent Storage:** All tasks are saved locally in your browser using `localStorage`, so you never lose your progress.
*   **Modern UI/UX:** A responsive, dark-mode-first design featuring custom typography (`Syne` and `DM Mono`), glassmorphic elements, smooth CSS animations, and toast notifications.

## 🛠️ Tech Stack

*   **HTML5** (Semantic structure)
*   **CSS3** (Custom variables, Grid/Flexbox layouts, CSS animations)
*   **Vanilla JavaScript** (DOM manipulation, state management, array sorting/filtering)
*   **Local Storage API** (Data persistence)
